## まず最初にやること
1. このフォルダの `AGENTS.md` を最後まで読む。決まりごと・確定したデザイン・やってはいけないこと・未決定の項目がすべて書いてあります。
2. `python3 -m http.server 8000 --directory site` で開き、PC幅とスマホ幅(390px)の両方でページを上から下まで見る。
3. `npm install && npx playwright install chromium && npm run verify` を回し、`verify-out/` の画像を見て、今の状態がすべて OK なことを確かめる。
4. ここまで終わったら、ユーザーに「引き継ぎました」と短く伝え、次に何をしたいかを聞く(勝手に大きく作り替えない)。
