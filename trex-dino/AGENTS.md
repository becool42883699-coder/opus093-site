# AGENTS.md — T-rex株式会社 1ページのホームページ(目で追う恐竜)

このフォルダで作業するエージェント向けの決まりごと。**作業を始める前に全部読むこと。**
ユーザーとのやり取りは日本語。

## これは何か

福岡県北九州市の T-rex株式会社(鈑金塗装・荷台換装・出張修理 ほか)の1ページのホームページ。
ヒーローでは、ヘルメットをかぶった青い恐竜(3DCG風のキャラ画像)が、**マウスや指の動きを目で追う**(WebGL)。
ビルド工程は無い。素の HTML / CSS / JS だけで、`site/` をそのまま静的ホスティングに置けば動く。

```
site/                     公開するもの(これがすべて)
  index.html              ページ本体。HTML・CSS・ページ側 JS(恐竜の動きの制御・レイアウト・現れる演出)がこの1枚に入っている
  dino/dino-renderer.js   恐竜の WebGL 描画(シェーダー)。window.TrexDino.makeRenderer を公開
  dino/geo.js             目の座標・可動範囲(元は画像解析の生成物。手で編集しない)
  assets/                 base.webp(目を抜いたキャラ画像)/ eye-atlas.png / mask-atlas.png / fallback.webp(静止画の控え)
                          logo-arc-white.svg(公式ロゴ・白一色)/ works/(施工実績の実写6枚)
brand/                    ロゴの原本(ユーザー支給。書き換えない)
reference/                最初にチャットで作られた1ファイル版(見た目・動きの原点。参考用)
tools/verify.mjs          確認スクリプト(下記)
tools/logo_reverse.py     背骨ロゴを濃い面用の色に変える道具(今は未使用)
```

## 動かし方・確認のしかた

```
python3 -m http.server 8000 --directory site      # または npx serve site
```
`file://` で直接開くと WebGL がテクスチャを読めない。必ずローカルサーバー経由で開く。

変更したら毎回、確認スクリプトを回し、**出てきた画像(verify-out/)を自分の目で見る**:
```
npm install && npx playwright install chromium
npm run verify
```

## 最重要ルール

1. **スマホ(390px前後)で必ず確認してから完了報告する。** PC だけ見て終わらない。iPhone SE(375×667)でヒーローのボタンが
   恐竜のヘルメットに重ならないこと。横にはみ出さないこと。演出の上でも縦スクロールが効くこと。
2. **JS無効・動きを減らす設定でも全文が読めること。** 現れる演出は `<head>` のインラインで `html.js` を付けた時だけ隠す作り。
   `[data-rv]`(フェードアップ)/ `[data-ln]`(行ごとにせり上がる)/ `[data-ph]`(写真の幕)。IntersectionObserver で `.in` を付ける。
   reduced-motion の上書きは、`.in` 付きのセレクタの方が詳細度が高いので **`.in` 付きも並べて** 書く。
3. **すぐ電話したい人の導線を消さない。** スマホのヘッダーの白い電話ボタン、メニュー下の電話番号、PC(1100px以上)のヘッダーの番号、
   問い合わせの大きな電話番号と「電話をかける」。
4. **依存を増やさない。** フレームワーク・ビルド工程・npm の実行時依存は入れない(playwright は確認用の開発依存だけ)。

## デザインの決まり(ユーザーとのやり取りで確定したもの)

ユーザーの要望は「**ヒーローの世界観で一体感を。見た人に“かっこいい”と思わせたい**」。
1回目の作り(ステッカー風のピル型ラベル・金属っぽい線・角丸の黒いカード・線画アイコン・流れる帯)は
「**全体的に普通。安っぽいところが多い**」と言われて作り直した。**これらは戻さない。**
今の作りは「スタジオで撮った広告」: 文字の大きさ・余白・細い罫線で見せる。角は立てる(写真の角丸は 3px)。

- **面は3つだけ**: 青 #0164cc(ヒーローのスタジオ)/ 黒 #08090b(ヘルメット)/ 白。
  並び: ヒーロー(青)→ 事業(青)→ 施工実績(黒)→ エリア(青・上から照明 `.studio`)→ 会社(白)→ 採用(黒)→ 問い合わせ(青・照明)→ フッター(黒)。
  差し色はシアン #00cfff(ヘルメットの「T」の色)を小さく使うだけ。
- **見出しの型**: `.shead`「(01) SERVICE ──── 事業内容」→ 和文の大見出し `.h2`(Noto Sans JP 700・palt)。
  **見出しの改行は `<span class="ln"><span>…</span></span>` で手で切る**(自動だと「ます。」だけ次の行に落ちた)。
- **書体**: 和文 Noto Sans JP。欧文ラベル・数字は Archivo の細幅(`--cond`、font-stretch 72〜78%)。
  斜体ワイドの Archivo(`--wm`)はヘルメットの社名の字に近いので、**電話番号だけ**に使う。
- **事業**: 巨大な動詞「直す。/ 変える。/ 駆けつける。」+ 鈑金塗装 / 荷台換装 / 出張修理。マウスを乗せると行全体に
  ヘルメットの黒い光沢が左から満ちる(hover できる端末だけ)。クラス名は `.srow`(`.row` はフッターとぶつかる)。
- **施工実績**: 荷台換装の3枚を「Before / Process / After」の流れで、残り3枚は「そのほかの施工」。スマホは横にめくる帯(scroll-snap)。
  写真の幕は `li[data-ph]` を監視して中の `.shot` を clip する(clip した要素自身は IntersectionObserver が反応しないため)。
- **エリア**: 路線図のように 福岡県 ― 北九州(拠点)― 山口県。
- **会社**: 白い面に大きな数字(2025年1月 / 300万円 / 7事業)と諸元表。

### ロゴ(確定)
- **全部、弧のロゴの白一色**(`site/assets/logo-arc-white.svg`。ヒーローの左・ヘッダー・メニュー・フッター・会社)。
  原本は `brand/T-Rex_arc.ai`(紺 #04113b ＋ブルー #005bff)。原本の色だと青い面でブルーが、黒い面で紺が消える
  (PC のヘッダーが「T-Re>」に見えた)ので、ユーザー判断で白にした。**原本の色に戻さない。**
- ヘッダーのロゴは高さ 72px(スマホ 58px)より小さくしない(小さいと「ロゴが反映されてない」と言われた)。drop-shadow は掛けない。
- 背骨ロゴ(`brand/T-Rex_spine.*`)は前に使っていた別案。今は使っていない。

### 恐竜(WebGL)まわり — 触る時は特に慎重に
- 黒目の静止位置は元の絵のまま(少し寄り目でこちらを見る)。まぶた輪郭は手で引いたもの。元の絵の画素はできるだけ描き替えない。
- 目のアセット(base / eye-atlas / mask-atlas / geo.js)を作り直す Python の道具は**このフォルダに無い**(ユーザーの手元にある)。
  目まわりを変える依頼が来たら、まずユーザーにその道具を渡してもらう。
- 調整できる値: 黒目の動く量 = index.html の `draw(..., .85)` の最後の引数 / 目と頭の速さ = `spring(..., 26 / 4.2, dt)` /
  まばたき = `blinkAmt()` / 頭の振れ幅 = dino-renderer.js の `disp()` 内 `uHead*4.` と `uHead*16.`。
- WebGL 非対応・JS無効では `img.dino`(fallback.webp)を出す。この img は `max-width:none`(全体の `img{max-width:100%}` で縮んで崩れた)。
