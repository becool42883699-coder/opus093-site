# シグネチャ演出カタログ

## 思想(最初に読む)

- **1ページに1点だけ。** シグネチャは「記憶に残る1点」。複数入れると全部が薄まり、逆にAI生成っぽくなる。選んだ1点に負荷と視線を集中させ、他の要素はすべて静かに保つ。
- **業種の現場から発想する。** 道具・素材・動作・図面など「その仕事にしかない物」を画面の動きに翻訳する。どの業種にも貼れる汎用エフェクトは選ばない。
- **演出は情報。** 動きが内容の理解を助けるか、ブランドの何かを語るなら採用。ただの飾りなら削る。

## 選定プロセス(4ステップ)

1. クライアントの現場にある「道具・素材・動作・図面」を3つ書き出す
2. それぞれを「画面上で何が起きるか」1行に翻訳する
3. 実装コスト・描画負荷・モバイルでの成立性で1つに絞る
4. 「共通実装ルール」に従い、プロンプトまたはコードに落とす

## 業種→演出の逆引き

| 業種 | 第一候補 | 次点 |
|---|---|---|
| 工務店・不動産・設計事務所 | A1 線画ドロー(間取り図) | E2 図面⇄写真クロスフェード |
| 塗装業・美容・アート系 | D1 刷毛ストローク | B2 画像カーテンリビール |
| 板金・金属加工・ジュエリー | D2 光沢スイープ | C3 スクラブ分解 |
| 中古車販売・整備・旅行 | C1 被写体固定・背景差し替え | C3 スクラブ分解 |
| カフェ・飲食 | A1 線画ドロー(抽出器具・調理道具) | A3 手書き下線 |
| 士業・教室・スクール | A3 手書き下線・丸 | A2 罫線ドロー |
| 写真スタジオ・アパレル | B2 画像カーテンリビール | B1 見出しの幕上げ |
| 製造業・機械 | C3 スクラブ分解 | A1 線画ドロー(機構図) |

## カタログ

### A. 線・描画系

**A1 線画ドロー(SVG stroke-dashoffset)**
業種の図面(間取り図・機構図・回路・抽出器具)が線で描かれていく。各pathに `pathLength="1"`、CSSで `stroke-dasharray:1; stroke-dashoffset:1` を初期状態にし、IntersectionObserverの一回発火で `stroke-dashoffset:0` をtransition。pathごとに `transition-delay` をずらして順番に描く。
注意: 線幅1.4px前後、色は2色まで、描画は合計1.6秒以内、path数は10本程度まで。

**A2 罫線ドロー**
見出し脇やセクション区切りの水平線が `transform: scaleX(0→1)`(transform-origin: left)で伸びる。どの業種にも合う控えめ版で、単体ではシグネチャとして弱い。タイポグラフィと組み合わせて「所作」として使う。

**A3 手書き下線・丸**
見出しのキーワードに手書き風SVG(下線・丸)がドローされる。フリーハンド風のpath 1本で足りる(ライブラリ不要)。士業・教室・カフェ向き。
注意: 1ページ2箇所まで。多用すると幼くなる。

### B. マスク・出現系

**B1 見出しの幕上げリビール**
見出しが行ごとに `overflow:hidden` の枠内で `translateY(100%→0)` で立ち上がる。高級系全般に合う。行分割はspanで行い、JSライブラリは使わない。
注意: 日本語の折返し位置に注意。レスポンシブで行が組み変わっても破綻しない分割にする。

**B2 画像カーテンリビール**
写真の上に重ねた無地パネル(背景色と同色)が `translateX` で退き、写真が現れる。同時に画像側を `scale(1.06→1)`。建築・写真・アパレル向き。
注意: 画像自体をclip-pathで切るより、上のパネルを動かす方が軽い。パネル退場は0.9秒前後。

**B3 端のソフトフェード**
横スクロールギャラリーの両端を `mask-image: linear-gradient(...)` で溶かし、「続きがある」ことを示す。演出というより設え。ギャラリー併用時の補助として。

### C. スクロール連動系

**C1 被写体固定・背景差し替え**
sticky区間で被写体(車・商品)は画面に固定され、背景・シーンだけがスクロールで切り替わる。`position: sticky` + 背景レイヤーのopacityクロスフェード。中古車・旅行・プロダクト向き。
注意: 背景素材の用意が本体。動画より静止画クロスフェードの方が軽い。動画を使うなら遅延読込とposter必須。

**C2 数字カウントアップ**
実績数値(棟数・C値・創業年数)がスクロールインで加算表示。IO一回発火 + requestAnimationFrame、1.2秒、イージングあり。
注意: AI生成LPの典型演出なので、単体でシグネチャにしない。数字が本当に強いクライアントの補助演出としてのみ。

**C3 スクラブ分解**
スクロール量に応じて製品が部品に分解/組み上がる。画像シーケンス(sticky + canvas)またはThree.js。GSAP ScrollTrigger可。機械・時計・車向き。
注意: 最重量級。素材制作コストが本体。モバイルはシーケンス枚数を半分に。これを選ぶなら他の演出はゼロにする。

**C4 素材パララックス**
業種の素材(木目・布・紙・塗料)が背景で前景と違う速度で動く。`translateY` のみ、移動量はviewportの8%以内。効果というより空気づくり。

### D. 質感系

**D1 刷毛ストローク**
見出し背景やセクション区切りが「刷毛で塗られる」ように現れる。刷毛跡形状のSVGをmaskにして `scaleX` またはdashoffsetで進行。アクセント色をクライアントの実際の塗料色にすると効く。
注意: ブラシ形状は本物の刷毛跡を1回撮影/トレースして使うと一気に本物になる。既製の筆ブラシ素材は嘘っぽい。

**D2 光沢スイープ**
ロゴやCTAの上を細い光の帯が一度だけ走る(gradientのtranslateX、0.8秒)。初回表示時またはホバー時のみ。板金・ジュエリー・自動車向き。
注意: ループさせない。ループした瞬間に安い広告になる。

**D3 質感テクスチャ(静的)**
紙・和紙・金属のテクスチャを背景に敷く。動かさない。`feTurbulence` 等の動的生成は重いので静的画像で。シグネチャの土台として他と併用可。

### E. インタラクション系

**E1 マグネットボタン**
カーソルがCTAに近づくとボタンが吸い付くように追従(pointermove + transform、減衰付き)。クリエイティブ・制作会社向き。
注意: `@media (hover:hover) and (pointer:fine)` でデスクトップのみに限定。BtoBの堅い業種では逆効果。

**E2 図面⇄写真クロスフェード**
施工事例カードにホバーすると写真⇄間取り線画が入れ替わる(opacityクロスフェード0.5秒)。A1で作った線画資産を再利用できる。工務店・設計事務所向き。
注意: タッチ環境ではタップでトグル+「図面を見る」ラベルを付ける。

**E3 可変フォント伸縮**
スクロールやホバーで見出しの `wght` / `wdth` がぬるっと変わる。variable font必須。日本語フォントは非対応が多いため英字見出し限定。本文には絶対使わない。

### F. 一回もの

**F1 ファーストビューのロゴ線画**
初回訪問のみロゴが線で描かれてからページがフェードイン。合計1.5秒以内厳守。2回目以降はsessionStorage判定でスキップ。スキップ不能なローディング演出は作らない。

## 禁じ手(選ばない)

パーティクル背景 / 意味のない3D(地球儀・ブロブ) / 常時ループするグラデーションアニメ / 汎用のカーソル巨大化 / タイプライター演出 / 全要素へのズームイン一括適用(AOS的な使い方) / カウントアップの多用。いずれも「どの業種にも貼れる」時点でシグネチャ失格。

## 共通実装ルール(全演出に適用)

- アニメーションさせるのは `transform` / `opacity` / `clip-path` / `stroke-dashoffset` のみ。width・height・top等のレイアウトプロパティは禁止
- `prefers-reduced-motion: reduce` では全演出を無効化し、**最終状態**を静的に表示する(隠れたままにしない)
- スクロール連動の第一候補はCSS scroll-driven animations。必ず `@supports ((animation-timeline: view()) and (animation-range: entry))` で囲い、非対応ブラウザ(Firefox等)では「表示されている」を初期状態にする。装飾目的ならフォールバック不要、機能に関わる場合のみIntersectionObserverでフォールバック
- `animation` ショートハンドの**後**に `animation-timeline` を宣言する(先に書くと上書きされる)
- 一回発火は IntersectionObserver + `disconnect()`
- ホバー前提の演出(D2・E1・E2)はタッチ環境で無効化するか、タップ代替を用意する
- 演出のためだけに大型ライブラリを入れない。GSAP / Three.js はC3のような必然がある場合のみ
- 未使用のコード・import・依存を残さない
- modern-web-guidance スキルが利用可能な環境では、実装前に該当パターンを検索して最新のベストプラクティスに従う

## デザインプロンプトへの組み込みテンプレ

jiro式プロンプトの「シグネチャ要素」欄には、この形式で1点だけ指定する:

```
## シグネチャ要素(このページの記憶に残る1点)
[演出名]: [何が起きるかを2〜3行で具体的に]。トリガーは[スクロールイン/ホバー/初回表示]。
他の装飾はすべて控えめにし、この1点に負荷と視線を集中させること。
prefers-reduced-motion では無効化して最終状態を表示。transform/opacity系プロパティのみ使用。
```

記入例(A1・工務店):
「間取り図の線画SVGがスクロールに合わせて描かれていく演出(stroke-dashoffsetアニメーション)。ヒーロー背景とセクション間の仕切りに配置し、設計事務所らしさをこの1点に集約する。他の装飾はすべて控えめに。」
