# A / — 制作メモ

指定のデザイン画像1枚（注記入りのカンプ）を、そのままHTMLに起こしたもの。
配信物は `public/a-studio/index.html` の1ファイル＋ `img/` だけ。npm依存もビルドも不要で、
フォルダごとどこへ置いても動く。

## 画像内の注記＝実装した動き（7つ）

| カンプの注記 | 実装 | どこ |
|---|---|---|
| ヘッダー：スクロールでフェード / 固定 | `position:fixed`。ヒーローを抜けたら下地（紙色＋blur＋ヘアライン）がフェードイン。暗い面の上では下地ごと暗転して文字色も反転 | `.hdr` / JSの `hdrSolid` `hdrTone` |
| Hero：ゆっくり拡大 / 背景は微差パララックス | 背景が28秒かけて 1.005→1.11 へ拡大。スクロール時は背景 7vh / 前景テキスト 19vh と**速さを変えて**動かし、前景はフェードアウト | `.heroBg` / `.heroBgIn` / `.heroInner` |
| 縦ライン：進行に合わせて伸長 | セクションの通過率を `--lp` に入れ、ヘアラインを `scaleY` で上から伸ばす | `.vline[data-line]` / `[data-line-host]` |
| このセクション：左テキスト固定 / 右画像だけ切り替え | 300svhの区間を `position:sticky` でピン留め。左は一切動かさず、右の写真だけ 01→02→03 とクロスフェード。カウンタと写真内のキャプションも連動 | `.apStage` / `.apMedia` |
| 横スクロールでスライド | 縦スクロール量を横方向の `translate3d` に変換（PC）。モバイルは素のスワイプ（scroll-snap） | `.worksPin` / `.worksTrack` |
| 暗転して次セクションへ接続 | 手前のセクションの下端からグラデーションで黒へ落ち、黒い面が `sticky` で画面を覆う。抜けると次のCTAが黒から立ち上がる | `.dark` / `.dark::before` / `.darkStage` |
| 最後にCTAが静かに出現 | 他より長い尺（2s）と大きいstagger（0.22s）で、最後だけゆっくり出す | `.cta [data-reveal="lines"]` |

## カンプとの寸法合わせ（実測して合わせたもの）

カンプの和文グリフの送り幅を測ると、見出しは**ページ幅の 1.9〜2.0%**（1440pxなら28px前後）。
最初は 2.9〜3.35vw で組んでいて1.5倍大きく、そのぶん各セクションが間延びしていたので合わせ直した。
本文（1.02vw）と欧文ラベル（0.75vw）は最初から一致していた。

| | カンプ | 実装 |
|---|---|---|
| 見出し（ヒーロー / 各セクション） | 2.00 / 1.92vw | `clamp(22px,2.1vw,36px)` / `clamp(21px,2.0vw,34px)` |
| APPROACH の 文字 : 写真 : 右余白 | 26 : 39 : 24% | 23 : 41 : 16%（1440pxで 357 : 591 : 227px） |
| APPROACH の写真の比率 | 1.27 : 1 | 1.26 : 1 |
| 「01 / 03」の位置 | 写真の外・右余白の92% | 右余白の93% |
| WORKS のタイル比率 | 1.44 : 1 | 1.44 : 1 |
| WORKS のタイル間 | 隙間なし（1本のフィルム） | 隙間なし |

カンプの WORKS は5枚写っていて（1枚目が左で切れ、5枚目が右から覗く）キャプションは4つ。
横スクロールが成立する枚数なので **05 を足した**。画像はヒーローの水平線から起こし、
タイトル `Horizon` はこちらで付けた。

## 作りの決まり

- **モーションのトークンは5つだけ**（`--dur` / `--dur-slow` / `--ease` / `--stagger` / `--rise`）。
  演出の種類ごとに値を変えない。新しい動きを足す時もこのトークン経由で書く。
- **面の色は2つだけ**。紙 `--paper` と暗 `--dark`。中間色を増やさない。
- **JS無効・reduced-motion で内容が欠けないこと。**
  「アニメ前」の状態（`opacity:0` 等）は全て `[data-anim="on"]` の配下に置いてある。
  JSが動かなければ属性が付かず、静的な縦積みのページとして全文が読める。
  APPROACHの3枚も既定では縦に積む（重ねてのクロスフェードは `[data-pin="on"]` のときだけ）。
- **スクロール連動は rAF 1本**に集約。`scrollY` が変わらないフレームは何もしない。
- **ピン留めの境目は 1180px**。これより狭いと4カラムのテキスト段が本文1行分に足りず、
  1024pxで本文が、900pxで見出しまで途中で折れていた。下回る幅では
  APPROACH は縦積み＋横スワイプ、WORKS は素の横スクロールに落ちる。
- ヒーローの高さは `100svh`（`100dvh` はiOS SafariでURLバーに追従して高さが動く）。
- `touch-action:none` を持つ要素は1つも無い（縦スクロールを殺さないため）。

## 検証済みのこと

Chromium（Playwright）で確認。**WebKitは未インストールのため、iOS Safariの実エンジンでは未検証**。

- 横スクロールの発生なし: 360 / 390 / 820 / 1440px、reduced-motion時・JS無効時も含めて全て `scrollWidth == clientWidth`
- スクロール連動: APPROACHの写真が 01→02→03、WORKSの `translate3d` が 0 → -671px、縦ラインが 0 → 1
- JS無効: 全見出し・全本文・APPROACHの3枚・月まで表示される
- reduced-motion: `data-anim` が付かず、`opacity:0` の要素ゼロ
- モバイル(390px, hasTouch): タッチでページが縦に流れる / WORKSとAPPROACHが横スワイプできる / カウンタが追従する
- コントラスト（背後の実ピクセルの明るい方2%を最悪ケースとして実測）:
  ヒーロー見出し 13.1:1 / ヒーローの欧文ラベル 5.5:1 / SCROLL 5.0:1 /
  本文グレー（紙地）5.8:1 / 写真上の白キャプション 6.3:1（最悪値・水面の写真）
  → **暗幕やグレーを薄くする時は必ず測り直すこと。**

## 差し替えが要るもの

- **写真10点は全部カンプからの切り出し**（`img/`）。元が941px幅のカンプなので解像度が足りない。
  本番では実写に差し替える前提。`<img>` と `background-image` のパスを入れ替えるだけで済むようにしてある。
  推奨サイズ: hero 2400×1400 / hero-sp 1200×1700 / approach・works 1600×1100 / stone-strip 400×1600 / moon 1600×1100
  - カンプに焼き込まれていた文字（ロゴ・ナビ・ヒーローの見出し・SCROLL・LIGHT/MATERIAL/HUMAN）は
    HTML側で本文として出すので、切り出す前に画像から消してある。
- **カンプに無くて補ったコピー**は3つだけ:
  - 縦書きの「続いてゆく、美しいほうへ。」… カンプの該当箇所が「続いてぐ、…」と崩れていたため、
    意味の通る形に直した。指定があれば1行変えるだけ。
  - APPROACH 02/03 のキャプション（SCALE/SILENCE/PRESENCE、WATER/HORIZON/TIME）…
    「右画像だけ切り替え」を成立させるには3枚分の文言が要るため。
  - 02/03の写真は WORKS のタイルと同じ素材を流用している（カンプに1枚しか無いため）。
  - WORKS 05 の `Horizon`… カンプの5枚目は55pxしか写っておらず起こせないため、
    ヒーローの水平線を切り出して当て、タイトルを付けた。
- 欧文は Cormorant Garamond、和文は Noto Serif JP を Google Fonts から読む。
  読めない環境では Hiragino Mincho ProN → Yu Mincho → 游明朝 の順にフォールバックする。
  自前ホストに変えたい場合は `<link>` を差し替える。
- JP / EN ボタンは見た目だけ（切り替え先の言語版が無いため）。

## 配信について

`public/` に置いたものは静的書き出しで `out/` へそのままコピーされるので、
このメモは `scripts/postprocess-pages.mjs` の `BUILD_ONLY` に入れて配信物から外してある。
`index.html` を配信時に縮めたい場合は、同スクリプトの `minifyMigiwaHtml` の対象に
`a-studio/index.html` を足せば同じ扱いにできる（現状は未設定＝読みやすいまま配信される）。
